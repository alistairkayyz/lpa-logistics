# Code Standards

## General

- Keep route and component files focused on a single page or responsibility
- Fix root causes — do not layer workarounds or add feature flags
- Do not mix unrelated concerns in one component or route file
- No inline comments explaining what the code does — only add a comment for a non-obvious constraint or workaround

## TypeScript

- Strict mode is required throughout the project (see `tsconfig.json`)
- Avoid `any` — use explicit interfaces or narrowly scoped types
- Validate unknown external input at system boundaries (e.g. form data) before trusting it
- Use `as const` for static navigation arrays and similar literal data

## TanStack Start / React

- Pages live in `src/routes/` as file-based route modules using `createFileRoute`
- Use `head()` on each route for page-specific `<meta>` and `<title>` tags
- Default to server components where possible; add interactivity only when needed
- Place shared UI in `src/components/`; page-specific inline components (e.g. `Detail`, `NotFoundComponent`) may live inside the route file
- Wrap interactive state (`useState`, `useRef`, event handlers, GSAP hooks) in client components

## Styling

- Use Tailwind utility classes and the CSS custom property tokens defined in `src/styles.css`
- No hardcoded hex, rgb, or raw oklch values in JSX — use token-based classes (`text-primary`, `bg-card`, etc.) or CSS variables
- Exception: GSAP `gsap.to` color animations may reference raw oklch strings since GSAP animates inline styles
- Follow the border radius scale from `ui-context.md`
- Custom utilities (gradients, shadows, grid backdrop) are defined in `src/styles.css` via `@utility` — use the class names (`bg-gradient-hero`, `shadow-glow`, `bg-grid`)

## Assets

- Images and logos are imported as ES modules from `src/assets/` (`import logo from "@/assets/lpa-logo.png"`)
- Do not use CDN asset URLs in component code — all assets must be local and bundled

## File Organisation

- `src/routes/` — One file per page/route
- `src/components/sections/` — Homepage and page section components
- `src/components/ui/` — shadcn/ui primitives (CLI-generated, do not edit)
- `src/components/` — Shared layout components (`SiteHeader`, `SiteFooter`, `PageHero`)
- `src/assets/` — Local images and logos
- `src/lib/` — Utilities and server config
- `src/styles.css` — Single global stylesheet; all tokens and font-face declarations live here

## Forms

- Use native HTML form elements for simple forms (contact page uses native `<form>`, `<input>`, `<textarea>`, `<select>`)
- Mark required fields with the `required` attribute
- Validate at submit; do not add redundant client-side validation on top of native HTML validation for simple fields

## Protected Files

Do not modify these unless explicitly instructed:

- `src/components/ui/*` — generated by the shadcn/ui CLI
- `src/routeTree.gen.ts` — auto-generated by TanStack Router; do not hand-edit
